# Reports

Reports capture provenance, comparisons, test evidence, and current judgments. They are subordinate to current user instructions, the constitution, and exact source artifacts.

- `20260808_inventory_and_provenance.md`: what was imported, how it was reconstructed, and what was checked before publication.
- `20260808_version_salvage_map.md`: concise keep/rewrite/reject map across the supplied lineages and Arena.
- `checksums/SHA256SUMS.txt`: integrity manifest for durable files under this workspace root, excluding the checksum file itself.

When adding validation evidence, state the exact device/API/build identity and use the evidence labels defined in `AGENTS.md`.
