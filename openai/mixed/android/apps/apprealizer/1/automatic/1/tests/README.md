# Tests and evidence

Store reproducible plans, fixtures, scripts, and non-private evidence here. Organize by candidate and environment.

Every result should record:

- candidate commit/hash and APK hash;
- Android API, device/emulator image, ABI, and acceleration state;
- install/upgrade/fresh-data conditions;
- permissions and special-access state;
- exact action, expected result, observed result, logs, and evidence label;
- cleanup and resource/leak observations.

Do not commit screenshots, notification contents, accessibility trees, clipboard data, or logs containing private user information.
