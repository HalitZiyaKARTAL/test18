# Overlays

This lane is for future overlay-specific designs, HTML controllers, native overlay components, visual self-localization, capture coordination, and RGB/vision tests.

Historical overlay prototypes remain under `../arena/`; do not edit them. New overlay work should document mode semantics (`PLACE`, `VISUAL`, `HIDDEN`), live-view state, capture presentation, ownership/epoch cleanup, safe-area behavior, and device/runtime evidence.
