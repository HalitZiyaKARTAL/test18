Create an Android app called HTML Realizer. It should act as a general app-making runtime: the user writes HTML/JavaScript, and the app gives that JavaScript broad Android capabilities through a bridge with Java and Kotlin reflection. It should be flexible enough to create many different tools without modifying or recompiling the native app. Important capabilities include reading and understanding the screen, clicking and performing gestures, reacting to notifications and other conditions, running appropriate background behavior, screen capture, vibration, alarms, and access to other Android functions wherever permissions allow.

Keep the important control surface native, outside the HTML/WebView, so broken, frozen, blank, or replaced HTML cannot make the app unusable. Native controls should include Bridge ON/OFF, Sandbox ON/OFF, editable Whitelist/Graylist/Blacklist, Cut HTML Internet ON/OFF, Internet exceptions, permission controls, and recovery options that restore the default editor or recreate the WebView. The Whitelist allows matching bridge operations and the Blacklist rejects them. Graylisted operations must show exactly four choices: Always allow (execute and move the rule to Whitelist), Allow once (execute once), Reject once (reject once), and Always reject (reject and move the rule to Blacklist). Only the first and last choices persist or modify lists; moving a rule removes it from Graylist.

“Cut HTML Internet” should block ordinary Internet access originating from HTML/WebView—including navigation and remote resources—but intentionally ignore Internet access performed through reflection.

Use this exact default HTML:

<!DOCTYPE html><title>HTML Realizer</title><style>body{margin:0;padding:4px;background:#111;font-family:monospace}div{min-height:40vh;background:#222;color:#eee;border:solid #444;padding:8px;white-space:pre-wrap;margin-bottom:4px;overflow:auto}button{border:0;background:#058;color:#fff;width:100%;height:5vh;font-size:2vh}</style><div id=i contenteditable="plaintext-only" oninput="c.textContent=i.textContent.length"></div><button onclick="var code=i.textContent;document.open();document.write(code);document.close()">Realize (<b id=c>0</b> characters)</button>
